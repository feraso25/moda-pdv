# ModaPDV

Sistema da loja de roupas: venda e caixa, peças com grade de tamanho e cor, etiquetas com
código de barras, condicional, trocas com vale-troca, crediário com carnê, sacolas montadas
pelo celular das vendedoras e clientes com aniversariantes. Funciona no computador da loja,
sem depender de internet.

Este repositório guarda só o **instalador** e as **atualizações automáticas** (aba Releases).
O programa avisa sozinho quando sai uma versão nova.

- Instalador: na aba [Releases](https://github.com/feraso25/moda-pdv/releases/latest), arquivo `ModaPDV-Instalador-<versão>.exe`.
- App das vendedoras (Android): release `vendedora-apk`, arquivo `ModaVendedora.apk`.
